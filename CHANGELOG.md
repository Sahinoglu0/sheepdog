# Changelog

**English** · [Türkçe](CHANGELOG.tr.md)

## v0.4: Sheepdog

- Licensed under Apache-2.0 with a credit requirement: `NOTICE` (forks and copies must keep it and show the credit) and `CITATION.cff`.

- The project is now **Sheepdog**, fully bilingual (English and Turkish): README, docs, roles, agents, skills, messages, the trial kit and the example cards.
- All file, folder and command names are English: `board.sh`, `state.sh`, `launch.sh`, `watchdog.sh`, `dry-run.sh`, `doctor.sh`, `settings.sh`, `main-branch.sh`, `rounds.sh`, `trust.py`, `lang.sh`; `jobs/`, `roles/`, `trial/`, `examples/`, `tests/`; card files `card.md`, `result.md`, `review.md`, `verification.md`, `merge.md`. State, role and card-field names are kept in English canonical form; the Turkish names are accepted as aliases (`lang.sh`, see `docs/LANGUAGES.md`).
- `sheepdog`: one front door (`board`, `watch`, `ready`, `start`, `set`, `rounds`, `timeline`, `policy`, `lang`, `new`, `doctor`, ...).
- `sheepdog policy ask|auto`: a persistent "ask before merging" switch (`.policy`), read by the manager before every merger launch.
- `sheepdog timeline` shows time per state per card; `sheepdog new` scaffolds a card.
- `main-branch.sh` detects the main branch; `dry-run.sh` and the merger no longer assume `main`.
- `rounds.sh` counts review rounds from `.history`, so the three-round limit no longer lives in the manager's memory.
- Sessions get only their own card folder; model and effort values are validated; `~/` project paths are expanded.
- `watchdog.sh` reports only after three consecutive `claude agents` failures. `board.sh` accepts several `Waits-for:` cards.
- Entirely new artwork: animated SVGs generated by `tools/build_assets.py` (banner, flow, lifecycle, chat demo, architecture, safety; in both languages).
- The smoke test grew to 255 checks. Fixes after an independent review: `main-branch.sh` no longer mistakes a checked-out feature branch for main; `watchdog.sh` survives unexpected JSON; `state.sh` rewrites only the first status line and keeps CRLF; capitalised states are accepted; model/effort may not start with a dash; a worker is not relaunched for a done card; the Turkish alias `incelemeci` works; the trust-model wording no longer overstates what `--add-dir` does.

## v0.3: easy to use

- `trial/`: a 10-minute trial that does not touch your own project: a small project with a deliberate bug and a missing feature, plus three cards.
- `examples/`: ten detailed example cards (bug, feature, tests, dependency upgrade, refactor, docs, performance, research, data report, dependent decision memo) and a card-writing guide.
- `settings.sh`: model and effort per role; `PROFILE=frugal|balanced|strong`; `Model:` / `Effort:` on a card for a single job's worker.
- `SHEEPDOG_DRY=1`: `launch.sh` prints the command it would run without opening a session.

## v0.2: Linux, macOS and Windows

- Scripts run on macOS (including its bash 3.2) and on Windows Git Bash; CI runs them on all three.
- `trust.py`: the trust check in one place; paths are normalized on every system. In a git repo the folder itself or the git root must be approved.
- `doctor.sh`: checks `python3` or `python`, git 2.38 and the Claude Code version without `sort -V`.
- `board.sh`: summary line, a warning for stuck cards, and a live view.
- Line endings pinned to LF through `.gitattributes`.

## v0.1: experimental first release

Tried with Claude Code 2.1.293 on Linux. Agents (manager, worker, reviewer, verifier, merger), the card-writing skill, the model-free scripts (board, watchdog, merge dry run), `launch.sh`, `state.sh`, example cards and the git-ignored `jobs/` folder.
